# Metronome & Boîte à rythmes — Présentation

Bienvenue ! Cette page présente les deux petits outils musicaux hébergés ou référencés depuis ce dépôt : pMetronome (métronome visuel PWA) et une Boîte à rythmes (step sequencer léger).

##Metronome

Metronome est un métronome visuel, conçu comme une Progressive Web App (PWA) :

- Tempo réglable (BPM)
- Choix de subdivisions et de signatures rythmiques
- Accents configurables
- Presets de rythmes
- Outils d'entraînement (boucles, progression de tempo, etc.)

Démo / dépôt

- Démo & source : https://github.com/thibautpe/metronome

Installation / utilisation

- Ouvrir la page dans un navigateur moderne.
- Pour une installation locale : cloner le dépôt pMetronome et ouvrir l'index dans un serveur statique (ou activer la page GitHub Pages si disponible).
- pMetronome inclut un manifest et un service worker pour une installation en PWA (manifest.webmanifest, sw.js).

## Boîte à rythmes — Step sequencer

La Boîte à rythmes est un petit séquenceur par pas pour créer des patterns et jouer des grooves :

- Interface simple par grille
- Lecture en boucle avec réglage de tempo
- Possibilité d'accentuer des pas et créer des motifs
- Idéal pour prototyper des idées rythmiques rapidement

Ressources

- Page dédiée (wiki) : K.O. II — boîte à rythmes web (voir les pages du dépôt)
